Case File 03 / Evidence Dossier

Solar Absorption Fridge

Solar-powered NH₃–H₂O absorption refrigeration research for off-grid use in Sudan and similar hot-climate environments.

Solar thermalThermodynamicsResearch / HOLD
Target

200 W cooling class

The current research baseline targets 200 W cooling for a 150 L cold box, with a modeled COP of 0.424.

Method

Model → validate → gate

The project combines Ziegler–Trepp thermodynamic implementation, CoolProp comparisons, CFD, CAD and a documented open-gap/decision register.

Validation

What has been established

Pure-fluid comparisons against CoolProp cover 12 states with a maximum absolute temperature difference of 0.63 °C and a mean of 0.32 °C. This is not mixture VLE validation; NH₃–H₂O mixture-data validation remains an open research item.

Engineering baseline

Evidence layer

The repository includes thermodynamic modeling, a 1.59 m² CPC collector basis, OpenFOAM heat-transfer work, FreeCAD/CadQuery/Build123D paths, component sizing and a 35-item quantity-only BOM.

Release status: HOLD. The repository explicitly states that the design is not approved for fabrication, pressure testing, ammonia charging or operation. Pressure/material/geometry/safety gaps must be closed before any build release.
